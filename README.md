# Платформа управления очередями (Student Queue)

Современное веб-приложение для организации очередей на сдачу лабораторных работ, курсовых проектов и экзаменов. Позволяет студентам удобно записываться, видеть, кто за кем, и не толпиться в коридорах. 

## 🚀 Особенности
* **Создание очередей без авторизации**: Любой может добавить новый предмет или создать очередь на определенный день.
* **Быстрая запись**: Ввод имени требуется только в момент нажатия на свободное место (для скорости и удобства).
* **Никаких паролей**: Для идентификации используется автоматически сгенерированный токен, хранящийся в браузере студента.
* **Гибкость**: Отсутствие жестких рамок. Студенты могут сами удалять устаревшие очереди, добавлять новые предметы и управлять потоком.

## 🛠 Технологии
* **Frontend**: React, Vite, TailwindCSS, Lucide-React
* **Backend**: Python, FastAPI, SQLAlchemy
* **Database**: PostgreSQL
* **Деплой & Контейнеризация**: Docker, Docker Compose

## 💻 Локальный запуск (через Docker)

Убедитесь, что у вас установлен [Docker Desktop](https://www.docker.com/products/docker-desktop/).

1. Склонируйте репозиторий и перейдите в папку с проектом.
2. Выполните команду для сборки и запуска:
   ```bash
   docker-compose up -d --build
   ```
3. Проект будет доступен по следующим адресам:
   - Фронтенд: [http://localhost:3000](http://localhost:3000)
   - Бэкенд (Swagger API): [http://localhost:8000/docs](http://localhost:8000/docs)
4. Чтобы сбросить базу данных и заполнить её предметами по умолчанию:
   ```bash
   docker-compose exec backend python -m backend.reset_db
   ```
5. Для остановки проекта:
   ```bash
   docker-compose down
   ```

## 🌐 Деплой (Выкладка в интернет бесплатно)

Для того чтобы проект работал онлайн 24/7 без оплаты серверов, используется микросервисная архитектура (бесплатные тарифы).

### Шаг 1: Подготовка
1. Опубликуйте этот код в **свой репозиторий на GitHub**. (Большинство сервисов берут код напрямую оттуда).

### Шаг 2: База данных (Neon.tech / Supabase)
1. Зарегистрируйтесь на [Neon](https://neon.tech) (или Supabase) и создайте новый проект с базой данных PostgreSQL.
2. Скопируйте строку подключения (`DATABASE_URL`). Она выглядит так: `postgresql://user:password@host/dbname...`.

### Шаг 3: Бэкенд (Koyeb / Render)
1. Зарегистрируйтесь на [Koyeb](https://www.koyeb.com) (рекомендуется) или [Render](https://render.com).
2. Выберите развертывание напрямую из GitHub.
3. Укажите следующие параметры сборки:
   - Папка/Каталог: `backend`
   - Команда сборки: `pip install -r requirements.txt`
   - Команда запуска: `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`
4. В разделе **Environment Variables (Переменные окружения)** добавьте:
   - `DATABASE_URL` = [Ваша строка из шага 2]
5. После деплоя вы получите ссылку на ваш API, например: `https://my-backend.koyeb.app`.

### Шаг 4: Фронтенд (Vercel / Netlify)
1. Зарегистрируйтесь на [Vercel](https://vercel.com).
2. Нажмите **Add New... -> Project** и выберите ваш репозиторий на GitHub.
3. В поле "Root Directory" выберите папку `frontend`.
4. В разделе **Environment Variables** добавьте:
   - `VITE_API_URL` = [Ваша ссылка на API из Шага 3, без слэша на конце]
5. Нажмите Deploy.

Всё! Ваша очередь работает в интернете и готова к использованию всей группой.
