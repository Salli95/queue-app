# Электронная очередь студентов (Student Queue)

Веб-приложение для удобной организации очередей на сдачу лабораторных, курсовых, показа презентаций и защиты проектов. 

## Особенности
* **Максимально просто**: Зашел -> Кликнул -> Вписал имена -> Занял место.
* **Без нудных регистраций**: Никаких логинов и паролей. Выступаете в паре? Просто впишите оба имени.
* **Optimistic UI (Оптимистичный интерфейс)**: Моментальный отклик интерфейса при занятии или освобождении очереди (не нужно ждать ответа сервера).
* **Светлая тема**: Строгий, приятный дизайн, который всегда остается светлым.
* **Фильтрация**: Очереди можно создавать на конкретные даты и удобно переключаться между днями.

## Стек технологий
* **Frontend**: React, Vite, TailwindCSS (v4), Lucide-React
* **Backend**: Python, FastAPI, SQLAlchemy
* **Database**: PostgreSQL
* **Деплой & Хостинг**: Render.com (Blueprint)

---

## Развертывание (Render.com)

Проект настроен для развертывания "в один клик" на бесплатном тарифе хостинга [Render.com](https://render.com) с помощью файла `render.yaml` (Blueprint).

### Особенности бесплатного тарифа Render:
1. **База Данных (PostgreSQL) живет 90 дней**: Бесплатная БД на Render предоставляется сроком на 90 дней (что отлично подходит под длительность одного учебного семестра). После этого срока её нужно будет пересоздать.
2. **Спящий режим бэкенда**: Если сайтом никто не пользуется 15 минут, бесплатный сервер "засыпает". При следующем заходе первое действие может занять около 30-50 секунд (пока сервер "просыпается"). Благодаря внедренному **Optimistic UI** на фронтенде, пользователи не замечают этой задержки при занятии мест!

### Как обновить проект на сервере:
Любой `git push` в ветку `main` на GitHub автоматически запускает процесс сборки и деплоя на Render.com.

## Локальный запуск (через Docker)

Убедитесь, что у вас установлен [Docker Desktop](https://www.docker.com/products/docker-desktop/).

1. Склонируйте репозиторий и перейдите в папку.
2. Выполните команду для сборки и запуска:
   ```bash
   docker-compose up -d --build
   ```
3. Проект будет доступен по ссылкам:
   - Фронтенд: [http://localhost:3000](http://localhost:3000)
   - Бэкенд (Swagger API): [http://localhost:8000/docs](http://localhost:8000/docs)
4. Чтобы сбросить БД (удалить все записи), выполните:
   ```bash
   docker-compose exec backend python -m backend.reset_db
   ```
5. Для остановки сервисов:
   ```bash
   docker-compose down
   ```
