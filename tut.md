# Учебный проект: Очередь на сдачу лабораторных и экзаменов

## Описание проекта
Это веб-приложение создано для учебной группы, чтобы удобно занимать очередь на сдачу лабораторных работ, курсовых проектов и экзаменов. Приложение позволяет студентам записываться на определенные предметы и даты, а также бронировать конкретное место в очереди (даже если предыдущие места еще свободны). 

Главная фишка: каждый студент может управлять только своей записью, что исключает случайное (или намеренное) удаление чужих мест в очереди. 

## Стек технологий
Для разработки приложения был выбран современный и популярный стек:
- **Frontend (Клиентская часть):** React, Vite, Tailwind CSS. Мы используем React для создания удобного и быстрого интерфейса. Tailwind CSS позволяет быстро и красиво стилизовать элементы. Интерфейс адаптирован как для компьютера, так и для мобильных телефонов.
- **Backend (Серверная часть):** FastAPI (Python). Очень быстрый и современный фреймворк для создания API.
- **База данных:** PostgreSQL. Надежная реляционная база данных для хранения информации о предметах, студентах и очередях. Работа с ней ведется через SQLAlchemy (ORM).
- **Развертывание (Деплой):** Docker и Docker Compose. Позволяют запустить весь проект (базу данных, сервер и клиент) одной командой, не устанавливая кучу программ на компьютер.

## Основные термины
- **API (Application Programming Interface):** Мост между фронтендом (то, что видит пользователь) и бэкендом (сервером, где хранится логика).
- **ORM (Object-Relational Mapping):** Технология, которая позволяет работать с базой данных (PostgreSQL) с помощью объектов Python, вместо написания сырых SQL-запросов. В нашем проекте используется SQLAlchemy.
- **Docker Compose:** Инструмент, который читает файл `docker-compose.yml` и поднимает сразу все нужные контейнеры (БД, Backend, Frontend) в единой виртуальной сети.
- **Слот (Slot):** Конкретное место в очереди под определенным номером.

## Как запустить проект?
Проект настроен для работы в Docker. Если Docker установлен:
1. Откройте терминал в папке проекта.
2. Введите команду: `docker-compose up --build`
3. После успешного запуска:
   - Фронтенд (сайт) будет доступен по адресу: `http://localhost:3000`
   - Бэкенд (API документация) будет доступен по адресу: `http://localhost:8000/docs`

## Особенности реализации
- **Бронирование конкретного места:** В базе данных очередь реализована так, что запись привязывается к номеру позиции. Если студент выбирает 5-е место, а места 1-4 пусты, он все равно встает на 5-е место.
- **Безопасность:** Идентификация студента происходит по простому токену или имени (в зависимости от текущей настройки авторизации), чтобы никто другой не мог снять его с очереди.
